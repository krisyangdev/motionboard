# Light Beam Effect

Motionboard shot name: Screen Projection Beams

Small laptops on black each throw a trapezoid beam of light with an app screen inside it. The beams swing, hand off, merge into one wide beam that carries a stat along its right edge, and the last laptop closes.

## Why it works

The beam is a trapezoid window and the screen sits fixed in screen space. When the beam leans, only its far edge moves and the near edge stays on the lid top, so a swinging beam changes which part of the screen shows while the text stays level and readable. On a black frame only the beam has content, so the eye follows the light. The three screens go dark, light, dark (code editor, build console, mail), so the same beam never repeats itself. Every sync beat lands inside a beam: the completion pill, the build status cell, the mail toast and a whole mail paragraph sit where the beam shows them. The stat comes last, outside the right slanted edge of the widest beam, reading upward, and the number 2.4× is the largest element in the only accent color, teal #2dd4bf. The laptop is a thin silver lid seen from behind with a slim base edge, and it ends as a thin chamfered slab.
