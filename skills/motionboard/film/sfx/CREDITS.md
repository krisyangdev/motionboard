# Sound effects for the launch film

All files are CC0 (public domain): no credit required.

- `click-*`, `soft-*`, `thud`, `bell`, `select`, `switch`, `swipe`, `drop`: from the Interface Sounds, UI Audio, Impact Sounds and Casino Audio packs by [Kenney](https://kenney.nl/), CC0.
- `key-*`: [Keyboard Soundpack #1](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes) by unicae_games, CC0.

| Name | Use |
|---|---|
| `click` (3 variants) | a button press, a tap, a selection |
| `key` (8 variants) | one keystroke; use `every` and `count` for typing |
| `soft` (3 variants) | a hard cut, a card or window landing |
| `thud` | a major reveal |
| `bell` | the logo payoff, a success |
| `select` | a choice confirmed, a toast |
| `switch` | a toggle, a tab change |
| `swipe` | something sliding in |
| `drop` | an item dropping into a list |

A name without a number (`click`, `key`, `soft`) rotates through its variants.
