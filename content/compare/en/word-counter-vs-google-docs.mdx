Word counting looks like a solved problem, and for a quick check it is. The difference shows up in where your text lives, which numbers you need and how the tool decides what a word is. This page walks through each decision, then tells you when to pick each tool.

## Which one shows the numbers you need?

Start from the numbers. The Word counter shows words, characters with spaces, characters without spaces and an estimated reading time. Google Docs opens a Word count dialog from the Tools menu that shows words, characters and pages, and it can also display the count while you type, including characters without spaces.

So the two overlap on words and characters. The Word counter is the one with reading time, and Google Docs is the one with pages. If your task is set in a number of words, either works. If it is set in pages or in minutes, pick the tool that shows that unit.

## Which one is quicker for text from somewhere else?

A snippet from an email, a web page or a chat message has no document yet. With the [Word counter](/tools/word-counter/) you paste it into the box and the numbers appear and update on every keystroke. With Google Docs you open or create a document, paste, then open the count from the Tools menu or switch on the live count.

When the text already sits in a Docs file, the situation reverses. Counting inside the file saves a copy and paste, and the page count comes with it.

## Why the two numbers can differ

Do not expect the same total from every tool. A word is not a fixed unit: programs decide how to treat hyphens, slashes and numbers. The Word counter relies on the browser's own word segmentation, which splits well-known into two words. LibreOffice Writer treats a hyphenated word whose hyphen is always visible, such as plug-in, as one word, according to its help page. Google Docs has its own rules as well.

For a limit that matters, count in the tool that will judge the text, or leave a margin of a few words. The [glossary entry on word count](/glossary/word-count/) explains the idea in more detail.

## When to pick Word counter

Pick the Word counter when the text comes from outside a document, when you want reading time, or when you want a count that ignores formatting. It is also the quicker choice when you do not want to sign in or create a file just to check a number.

## When to pick Google Docs

Pick the Google Docs word count when you are writing in Docs already, when you need the page count, or when you want the number visible beside your writing while you type.
